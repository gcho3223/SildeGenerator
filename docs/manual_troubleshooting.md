# 문제 해결

## 일반적인 문제

### Q: 플랏이 삽입되지 않습니다
**A:** 다음을 확인하세요:
- 입력 디렉토리 경로가 올바른지 확인
- 파일 이름 규칙이 맞는지 확인
- 파일 형식(PDF/PNG) 확인
- Status 창의 에러 메시지를 확인

### Q: Keynote가 응답하지 않습니다
**A:** 다음을 시도하세요:
- Keynote를 완전히 종료하고 다시 시도
- 이전에 생성한 출력 파일을 삭제
- 시스템 설정 > 보안 및 개인 정보 보호 > 접근성에서 권한 확인

### Q: "Permission denied" 에러가 발생합니다
**A:** 출력 파일이 Keynote에서 열려있는지 확인하고, 열려있다면 닫아주세요.

### Q: Systematic 모드에서 일부 샘플만 삽입됩니다
**A:** 다음을 확인하세요:
- 모든 샘플 디렉토리가 존재하는지 확인
- 각 디렉토리에 필요한 플랏 파일이 있는지 확인
- Job Version이 올바르게 설정되었는지 확인

### Q: DRC 모드에서 에너지 포인트가 잘못된 위치에 배치됩니다
**A:** 미리보기 영역에서 드래그 앤 드롭으로 순서를 조정한 후 다시 생성하세요.

## 에러 메시지 해석

### "Please select at least one step"
Event Selection에서 최소 하나의 step을 선택해야 합니다.

### "Please select at least one object"
Object 섹션에서 최소 하나의 오브젝트를 선택해야 합니다.

### "Please select at least one energy point or resolution/linearity"
DRC 모드에서 에너지 포인트나 Resolution/Linearity 중 하나는 선택해야 합니다.

### "File not found: ..."
지정된 경로에 플랏 파일이 없습니다. 경로와 파일명을 확인하세요.

## 버그 리포트
버그를 발견하셨나요? Status 창의 전체 에러 메시지를 복사해서 알려주세요.

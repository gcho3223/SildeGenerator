# Plot Setting

각 모드에서 삽입되어지는 plot의 크기와 위치를 조정합니다.
Setting->Plot 탭에서 설정할수 있습니다.

### Arrangement
plot 삽입 배열로 다음과 같이 설정할 수 있습니다.
- 1x1
- 1x2
- 1x3
- 1x4
- 2x1
- 2x2
- 2x3
- 2x4
1x1, 1x2, 1x3, 1x4 배열은 plot의 Position을 upper, center, bottom으로 위치 설정이 가능합니다.

### Size(width)
plot의 크기를 결정합니다.
Keynote 상에서 width만 조정하여 plot 사이즈를 조정합니다.
(Keynote에서 Arrange 설정의 Constrain proportions이 체크되어 있지 않으면 Height는 따로 조정해야합니다.)

### Preview
배열과 크기를 설정하면 preview에서 대략적인 모습을 볼 수 있습니다.
프리뷰 박스를 클릭하면 X, Y 좌표를 선택하여 위치를 지정할 수 있습니다.

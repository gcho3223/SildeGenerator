# Drag and Drop 모드 사용법

## 사용방법  
1. 삽입할 plot들의 배열을 선택합니다.  
2. 필요한 슬라이드 수를 지정합니다  
(1~10장 외에 직접 설정 가능합니다.)  
3. 프리뷰 박스에 삽입할 슬라이드를 드래그앤드랍으로 배치합니다.  
4. 위치를 바꾸고 싶으면 마찬가지로 드래그앤드랍으로 옮기면 되고,   
삭제는 backspacebar, delete키 외에 바깥으로 드래그앤드랍하면 삭제됩니다.  
5. GENERATE 버튼을 누르면 슬라이드가 생성됩니다.  

## 프리셋
기본 설정된 사이즈와, 위치를 사용자가 바꿀 수 있습니다.  
1. Settings->Plot 탭으로 들어갑니다.  
2. 배열별로 plot의 사이즈를 조정합니다.  
plot 사이즈는 Width가 조정되고 이 값의 비율에 따라 Height가 자동 결정됩니다.  
(keynote 앱에서 Constrain proportions가 체크되어 있어야합니다.)   
3. 위치를 조정하고 싶으면 프리뷰 박스를 클릭해서 x, y 값을 입력합니다.  
4. 프리셋은 Preset에서 Save 버튼을 눌러 저장합니다  
(저장경로: /Users/{username}/Library/Application Support/SildeMaker)  
마찬가지로 다른 프리셋은 Load로 불러올수 있으며 불필요한 프리셋은 Delete로 삭제할 수 있습니다.
